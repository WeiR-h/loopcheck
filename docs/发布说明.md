## 已准备的部署配置

`compose.yaml` 设置 `APP_PUBLIC=true`，对外版本只接受随包样例，禁用连接用户目录、手工要求接口和 MCP，并拒绝旧版任意源码导入。本地使用 `python run.py`，保留真实目录接入。单应用进程，共享一个浏览器执行槽位。

在已登录的 AWS 账户中部署前核验实际费用，保持总预算 100 元以内（模型20元、托管最多80元），不自动升级实例。需要持久卷保存数据库和预算。`APP_ALLOWED_HOSTS` 填实际域名，使用 HTTPS 反向代理；默认 compose 仅绑定本机端口。

供应商密钥只能进入服务器环境变量或不公开的 .env，不能进入源码仓库、视频或报告。`data`、`.test-data` 和桥接凭据不可发布。发布后从未登录浏览器实际检查 /judge 和模型连接，并保持评审期可用。
